# wiloucf.org

Website for Women in Lasers & Optics (WiLO) at UCF.

- **Officers:** edit events, gallery, board, Summit schedule and settings at https://app.pagescms.org (see the Officer Editing Guide). Please don't edit files in `data/` directly on GitHub.
- **Webmaster:** layout and page text live in `index.html`; behavior in `app.js`; editor forms in `.pages.yml`.
- **Local preview:** run `python3 -m http.server` in this folder and open http://localhost:8000 (opening index.html directly won't load the data).
